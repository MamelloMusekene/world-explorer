# 🌍 World Explorer | South Africa

> **Discover South Africa. Explore its provinces, cities, destinations and experiences — all in one place.**

World Explorer | South Africa is a modern, interactive travel website designed to help users discover South Africa through its provinces, cities, tourist destinations and local experiences.

The website combines a clean editorial-style interface with interactive features such as live weather information, destination exploration, interactive cards, maps and dynamically loaded destination imagery.

---

## ✨ Features

### 🇿🇦 Explore South Africa
- Explore South Africa's provinces
- Discover major cities and locations
- Browse popular tourist destinations
- Learn more about different regions across the country

### 🌤️ Live Weather
- View current weather conditions for selected locations
- Displays:
  - Temperature
  - Weather condition
  - Wind speed
  - Additional weather information
- Weather information is retrieved dynamically using the Open-Meteo API.

### 📍 Location & Maps
- View selected locations on Google Maps
- Quickly navigate from a destination to its map location
- Location information is dynamically generated based on the selected destination

### 🖼️ Destination Images
- Destination imagery is dynamically retrieved using Wikipedia and Wikimedia Commons
- Fallback imagery is provided when an image cannot be retrieved

### 🃏 Interactive Destination Cards
- Interactive province and destination cards
- Flip-card interactions provide additional information
- Designed to make exploring destinations more engaging

### 📱 Responsive Design
The website is designed to work across:
- Desktop computers
- Laptops
- Tablets
- Mobile devices

### 🎨 Modern Editorial Design
The interface uses a modern travel-inspired visual style featuring:
- Cinematic imagery
- Dark editorial sections
- Minimal typography
- Large visual elements
- Floating content cards
- Responsive layouts
- Subtle animations and interactions
